Slide 02 — Database Systems

Lanskap Sistem
Database

Relasional atau NoSQL? Mengenal berbagai jenis database dan kapan masing-masing tepat digunakan.

Data Center Modern
Relasional

Database Relasional (SQL)

Data disusun dalam bentuk tabel — mirip spreadsheet, tetapi jauh lebih powerful. Setiap tabel memiliki hubungan dengan tabel lain melalui primary key dan foreign key.

  • Menggunakan SQL untuk query data
  • Skema harus didefinisikan terlebih dahulu
  • Cocok untuk data dengan struktur yang jelas
  • Contoh: data pesanan, pelanggan, produk
Data yang Fleksibel
NoSQL

Database NoSQL

Dirancang untuk data yang tidak selalu cocok dalam format tabel. Lebih fleksibel dan mampu menangani berbagai jenis data secara bersamaan.

  • Document store — MongoDB, CouchDB
  • Key-value — Redis, DynamoDB
  • Column-family — Cassandra, HBase
  • Graph — Neo4j (untuk relasi kompleks)
Pilihan

Memilih DBMS yang Tepat

MySQL

Cocok untuk website, e-commerce, CMS. Mudah dipelajari, komunitas besar, banyak hosting yang mendukung.

Website & CMS

PostgreSQL

Cocok untuk aplikasi kompleks yang membutuhkan data integrity ketat. Mendukung JSON, geospatial, full-text search.

Aplikasi Kompleks

MongoDB

Cocok untuk real-time app dan IoT. Skema yang sering berubah? MongoDB menjadi solusinya.

Real-time & IoT
Rekap

Poin-Poin Penting

  • 01

    SQL = Tabel, NoSQL = Fleksibel

    Dua pendekatan berbeda, keduanya memiliki tempat masing-masing.

  • 02

    NoSQL Bukan Pengganti SQL

    Banyak perusahaan menggunakannya secara bersamaan.

  • 03

    Pilih Sesuai Kebutuhan

    Data terstruktur = SQL. Data fleksibel/real-time = NoSQL.
