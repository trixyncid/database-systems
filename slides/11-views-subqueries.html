View
Simpan & Gunakan Kembali

View

View adalah query yang disimpan dengan nama. Cukup panggil namanya, tidak perlu menulis ulang query-nya.

  • Membuat view "penjualan_bulan_ini"
  • Membuat view "pelanggan_aktif"
  • Tim bisnis dapat mengakses tanpa memahami SQL
  • Bedanya dengan tabel: view tidak menyimpan data sendiri
Subquery
Query Bertingkat

Subquery

Query di dalam query — seperti filter yang memiliki filter sendiri.

  • "Pelanggan yang belanjanya di atas rata-rata"
  • "Produk yang belum pernah dipesan bulan ini"
  • Bisa digunakan di WHERE, FROM, atau SELECT
  • Perlu diwaspadai: bisa lambat jika datanya besar
