Slide 03 — Database Systems

Dasar-Dasar
Data Modeling

Sebelum membuat database, kita perlu memahami cara memetakan data dari dunia nyata ke dalam struktur database.

Membedah Struktur Data
Konsep Dasar

Entity & Attribute

Entity adalah "benda" atau "konsep" yang ingin kita simpan datanya — menjadi nama tabel di database. Attribute adalah informasi yang melekat pada entity — menjadi kolom di tabel.

  • Entity: Pelanggan, Produk, Pesanan
  • Attribute Pelanggan: nama, email, alamat
  • Attribute Produk: nama, harga, stok
  • Setiap entity memiliki ID unik (primary key)
Hubungan antar Data
Relasi

Relationship

Entity tidak berdiri sendiri — terdapat hubungan antara satu dengan yang lain. Di database, hubungan inilah yang memungkinkan data saling terkait.

  • One-to-One: 1 Pelanggan = 1 Akun
  • One-to-Many: 1 Pelanggan memiliki banyak Pesanan
  • Many-to-Many: 1 Pesanan berisi banyak Produk, 1 Produk ada di banyak Pesanan
Rekap

Poin-Poin Penting

  • 01

    Entity = Tabel, Attribute = Kolom

    Pemetaan dari dunia nyata ke struktur database.

  • 02

    Relasi = Hubungan antar Tabel

    One-to-One, One-to-Many, Many-to-Many.

  • 03

    Primary Key = ID Unik

    Setiap baris data harus memiliki identitas tersendiri.
