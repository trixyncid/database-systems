ER diagram telah selesai — kini mentranslate-nya menjadi tabel yang dapat digunakan di database.

Struktur Database
Primary Key

ID Unik di Setiap Tabel

Primary key adalah kolom yang mengidentifikasi setiap baris secara unik. Tidak boleh ada duplikat, tidak boleh kosong.

  • Auto-increment ID: 1, 2, 3, ...
  • Bisa juga menggunakan kode: "ORD-2024-001"
  • Yang penting: unik dan konsisten
Foreign Key
Foreign Key

Kunci Penghubung antar Tabel

Foreign key adalah primary key dari tabel lain yang "dipinjam" untuk menghubungkan relasi.

  • pesanan.pelanggan_id → pelanggan.id
  • pesanan.produk_id → produk.id
  • Inilah yang memungkinkan data saling terkait
Rekap

Poin-Poin Penting

  • 01

    ERD = Blueprint, Tabel = Struktur Nyata

    Dari gambar ke implementasi database.

  • 02

    Primary Key = Identitas Unik

    Tidak ada duplikat, tidak ada null.

  • 03

    Foreign Key = Jembatan

    Menghubungkan tabel satu sama lain.
